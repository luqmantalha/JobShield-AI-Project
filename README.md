# 🛡️ JobShield AI

An AI-powered recruitment fraud detection platform that helps job seekers identify fake job postings, verify recruiters, and analyze offer letters using Google Gemini AI.

---

## 🚀 Features

- AI Job Scam Detection
- AI Offer Letter Verification
- Recruiter Verification
- AI Trust Score
- Risk Analysis
- Firebase Authentication
- Firestore Database
- Dashboard Analytics
- PDF Report Generation
- Responsive UI

---

## 🛠️ Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Firebase
- Firestore
- Google Gemini AI
- React Router
- Recharts
- jsPDF
- pdfjs-dist
- Mammoth

---

## 📊 Modules

### Job Verification
Analyzes job descriptions and detects scam indicators.

### Offer Letter Verification
Extracts document text and verifies offer letter authenticity using AI.

### Recruiter Verification
Checks recruiter legitimacy based on provided information.

### Dashboard
Displays analytics, recent scans, AI confidence, trust scores, and notifications.
